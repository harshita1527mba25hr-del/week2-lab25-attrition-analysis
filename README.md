Employee Attrition Prediction (Advanced)
##  Overview
This repository contains the coursework for **Week 2 Lab 26**, focusing on advanced employee attrition prediction using machine learning.  
The project applies Python-based HR analytics to identify key factors influencing employee turnover, combining data preprocessing, model building, and performance evaluation.

---

##  Objectives
- Inspect and preprocess the employee dataset  
- Train and evaluate classification models for attrition prediction  
- Use performance metrics (accuracy, confusion matrix, classification report)  
- Visualize prediction outcomes with clear plots and charts  
- Apply machine learning to real-world HR analytics scenarios  

---

##  Tools & Libraries Used
- **Python 3**  
- **Pandas** – for data handling and preprocessing  
- **Scikit-learn** – for building and evaluating machine learning models  
- **Matplotlib** – for visualizations
